# 🔢 Numerology Calculator

A dark, mystical numerology app built with React + Vite.

Enter your full birth name and date of birth to reveal your three core numbers based on the Pythagorean system.

## ✦ What it calculates

- **Life Path** — your life's purpose (from your birthdate)
- **Expression** — your natural talents (from all letters in your name)
- **Soul Urge** — your inner desires (from the vowels in your name)

## 📦 Single-file port

`ports/Numerology.dc.html` is a self-contained port of `src/components/NumerologyCalculator.jsx`. It has the same numerology engine and all four tabs (Calculator, Tree of Life, Compatibility, Saved), plus a few UX changes: visible tab buttons, hover/focus states, month/day/year date entry, and an illustrated Tree of Life.

**Open it:** double-click `ports/Numerology.dc.html`, or open it in a browser. There is no build step or install. It loads `support.js` from the same folder, so keep the two files together.

**Generated, not hand-maintained:** this port is produced by a design tool from the React component. Don't edit it by hand, because changes will be overwritten on the next sync. Change the React app and regenerate instead. `ports/github.md` records the sync metadata.
